# SpeedUp

SpeedUp is an AI-native hardware development platform for turning product requirements into editable engineering projects.

[Website](https://speed-up.ai) · [Blog](https://speed-up.ai/blog/) · [Discord](https://discord.gg/wzCJNNDD6D)

## Current capabilities

- Structure plain-language requirements into functional modules, power rails, and interfaces
- Generate structured, editable KiCad schematics
- Select real, sourceable components
- Package symbols, footprints, a bill of materials, and KiCad project files for engineering review

PCB generation is currently in development.

## Open hardware projects

These repositories contain editable hardware projects generated with SpeedUp:

- [nRF52832 smart ring](https://github.com/SpeedUp-Tech/nrf52832-smart-ring-kicad-schematic) — Optical PPG sensing, motion sensing, battery charging, and a low-noise 1.8 V rail
- [ESP32 retro gaming console](https://github.com/SpeedUp-Tech/esp32-retro-gaming-console-kicad-schematic) — Controls, MicroSD storage, display, USB-C power, and I2S audio
- [Mini synthesizer](https://github.com/SpeedUp-Tech/mini-synthesizer-kicad-schematic) — STM32 control, USB-C power, physical controls, and an audio codec path
- [24V ESP32 greenhouse controller](https://github.com/SpeedUp-Tech/24v-esp32-greenhouse-controller-kicad-schematic) — Watering, nutrient dosing, lighting, pH, EC, level, and temperature interfaces
- [Solar-powered LoRa weather station](https://github.com/SpeedUp-Tech/solar-lora-weather-station-kicad-schematic) — ESP32 outdoor and gateway nodes, environmental sensing, weather inputs, and LoRa-to-Wi-Fi connectivity
- [BLDC steering wheel controller](https://github.com/SpeedUp-Tech/bldc-steering-wheel-controller-kicad-schematic) — STM32G4 motor control, three-phase gate drive, rotor sensing, braking, USB, and hardware safety interlocks

## Direction

We are building toward an end-to-end workflow spanning product requirements, electronics design, validation, sourcing, prototyping, and manufacturing.

Our standard is hardware that can be built, tested, and used in the real world. The system is designed to help individual creators and small teams move from an idea to a complete prototype with minimal coordination overhead.

## Contributing

Each open hardware project is intended for engineering review before fabrication. Technical feedback, reproducible issue reports, component corrections, and design improvements are welcome in the relevant repository.
